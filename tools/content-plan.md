# Daily blog content plan

One post is published on the blog every day at about 8am WAT. This file sets the rules, the search keywords and the topic list. It is not published on the website (`tools/` is excluded in `_config.yml`).

To steer what gets written, edit the topic list below: add topics, reorder them, or delete ones you don't want. The next unused topic in the day's category is written first.

## Who the posts are for

Business owners, managers and IT staff at small and medium-sized organisations in Lagos and across Nigeria: offices, schools, hospitals, banks and fintechs, manufacturers, retailers and NGOs. Write for a smart reader who is not an engineer. Explain technical terms the first time they appear.

## Weekly category rotation

| Day | Category | Angle |
| --- | --- | --- |
| Monday | Cyber Security | Threats, protection and compliance |
| Tuesday | Networking | Connectivity, Wi-Fi, cabling, SD-WAN |
| Wednesday | Datacenter & Infrastructure | Servers, storage, backup, power, cloud |
| Thursday | Managed Support | Running IT day to day, support, costs |
| Friday | Systems Integration | Making systems work together, Microsoft 365, identity |
| Saturday | Cyber Security | Staff awareness and practical tips anyone can follow |
| Sunday | Any category | Plain-English explainer ("What is…?") |
